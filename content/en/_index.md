## Research

- **LLM security** — prompt injection attacks and defenses for code completion, detection of AI-generated code, watermarking and copyright auditing of system prompts.
- **Interpretability** — locating and filtering noisy training data at token level; recovering how knowledge is organised inside a model from neuron activation features.
- **Production engineering** — training-pipeline optimization, safety guardrails, agent security.

Concretely this involves gradient-guided greedy search for prompt engineering, syntax-tree extraction over code, multi-objective prompt co-optimization, gradient-masking based noise filtering, and clustering neurons by data and activation patterns.
